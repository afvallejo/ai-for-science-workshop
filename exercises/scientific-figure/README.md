# Scientific figure exercise

A 30-minute hands-on exercise for the AI for science workshop. Participants create a figure three times using identical synthetic data and study context:

1. A naïve prompt.
2. An advanced prompt with explicit scientific and output requirements.
3. Plan mode, human review and then execution of the same advanced task.

[Download the participant pack](participant_pack.zip), unzip it and start with [START_HERE.md](participant/START_HERE.md). The three folders keep inputs and outputs separate. The data contain 80 technical measurements from 40 cultures across 10 simulated donors. Compound_X and all measurements are fictional.

[Exercise slides](slides/Scientific_figure_exercise.pptx) · [Slide PDF](slides/Scientific_figure_exercise.pdf)

[Facilitator guide](facilitator/GUIDE.md) includes timing, numerical checks and a reference plotting script. Keep the reference figure until after participants finish. It demonstrates one acceptable descriptive representation, not the expected output of any prompt round.

This exercise uses the original descriptive-only dataset context. It does not use the separate statistical extension developed for the workshop. No hypothesis testing is required. The primary workshop presentation remains unchanged.
