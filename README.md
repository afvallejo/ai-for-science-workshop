## Try the exercise

Download this repository using **Code → Download ZIP**, unzip it and open the folder in Codex. Follow [the exercise instructions](demo/README.md). No package installation is needed to inspect the CSV files.

Keep the input files unchanged and save your work in `demo/live_outputs/`. Compare your findings with the answer key only after completing the audit. Without Codex, use a spreadsheet or text editor.

The data are entirely synthetic. Their deliberate inconsistencies are part of the exercise, and the values have no biological interpretation.

## Scope and limitations

The participant guide was written for the 39-slide workshop; its slide numbers refer to that version. The flow-cytometry dataset, analysis and experimental figure in those materials remain pending. They are not completed research results.

Product names, usage examples and provider policies reflect the preparation date recorded in the source guide. Consult the linked official documentation for current terms.

AI-generated slide artwork and teaching text require human review. No open-source reuse licence has been selected for these workshop materials.
